 🚗 Cálculo de Parcelas de Carro em Java

Este é um projeto simples desenvolvido em Java para fins de estudo sobre estruturas de repetição e lógica de programação.
O programa simula o cálculo de parcelas para a compra de um carro com base em um valor total e um critério de valor mínimo por parcela.

📌 Funcionalidades

*   Calcula o valor das parcelas dividindo o montante total pelo número de meses.
*   Utiliza estruturas de repetição (for / while) para incrementar a quantidade de parcelas.
*   Possui uma regra de negócio que interrompe o cálculo (break)

 🛠️ Tecnologias

*   Java SE (Java Development Kit)
*   IntelliJ IDEA (IDE utilizada para o desenvolvimento)
*   Git & GitHub (Controle de versão e hospedagem)
